# Aura Dracin

Portrait-first Dracin (Drama Cina) streaming platform for Indonesian millennials & Gen Z.

## App

Real website lives in [`web/`](./web/):

```bash
cd web
cp .env.example .env
npm install
npm run dev
```

Set `DRAMABOS_API_KEY` from [dramabos.live](https://dramabos.live) to enable live short-drama feeds.
